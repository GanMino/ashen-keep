# 烬夜古堡 · ASHEN KEEP

**[在线游玩](https://ganmino.github.io/ashen-keep/)** · [GitHub 仓库](https://github.com/GanMino/ashen-keep)

横版像素动作肉鸽，可直接在浏览器中运行。三种职业穿越随机生成的古堡，击杀怪群、选择赐福、收集遗物，并逐层挑战亡王。

## 运行

需要 Node.js 20+（建议 22）。

```sh
npm install
npm run dev
```

开发地址默认 http://127.0.0.1:5188 。生产构建：`npm run build`，预览：`npm run preview`。`dist/` 可放到静态服务器，资源使用相对路径。游戏无需网络素材服务或 API 密钥。

## 操作

- A / D 或 ← / →：移动
- Space / W / ↑：跳跃；解锁后二次按下可二段跳
- J（按住）或鼠标左键：普通攻击
- K：职业范围技能
- Shift / L：短暂无敌冲刺
- E：房门、宝箱、圣所、楼层出口交互
- M：楼层地图
- Esc：暂停 / 继续
- 升级面板：点击或数字 1 / 2 / 3
- 手机支持屏幕触控，建议横屏游玩

## 当前版本

- 灰烬骑士：高生命、宽范围横扫、月刃风暴。
- 余火女巫：双发火球、爆裂范围魔法。
- 暗夜游侠：快速穿透箭、千羽齐射。
- 每局随机 3–5 层，每层 10–12 个连通房间，包含战斗、宝库、圣所、两处精英和一处 Boss。
- 首次击杀精英依次解锁二段跳和破障冲刺；探索之前锁定的秘库可获得额外遗物。
- 8 类可叠加赐福；金币用于圣所治疗；经验升级提供随机三选一。
- 房间怪物和物品状态在当前楼层内保留；最高击杀纪录和静音设置本地保存。
- 像素绘画场景、动态火炬、月光、角色动画、命中粒子、合成音效。

这是可玩的初版：Boss 使用同一套基础形态随楼层增强，尚未加入剧情任务、长期天赋树、局中存档、手柄或联网功能。移动端做过浏览器尺寸和触控验证，尚未做实体手机性能测试。

## 技术与验证

TypeScript + Vite + Three.js。960×540 像素绘画纹理经 Three.js 全屏着色器呈现；物理采用 60Hz 自定义二维平台碰撞，不包含复杂刚体。素材均为本地绘制，无生成资产任务。

`npm test`：随机地图与关键玩法回归。`tests/browser-check.mjs`：Playwright 实际按键/触控流程。测试钩子仅在开发模式或 `?test=1` 下暴露。

开发过程的设计、截图和验证记录保存在本地 `artifacts/` 目录，不随公开仓库上传。

## GitHub Pages

仓库包含 GitHub Actions 自动发布配置。每次推送到 `main` 后会执行测试、构建并发布到 GitHub Pages。在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。无需后端服务，打开发布地址即可游玩。
