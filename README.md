# 烬夜古堡 · ASHEN KEEP

**[在线游玩](https://ganmino.github.io/ashen-keep/)** · [GitHub 仓库](https://github.com/GanMino/ashen-keep)

横版像素动作肉鸽。三种职业穿越随机古堡，追寻少女莉娅的记忆，挑战空心王并决定古堡的命运。

## 运行

需要 Node.js 20+，建议 22。

```sh
npm install
npm run dev
```

开发端口 5188。`npm run build` 构建，`npm run preview` 预览。`dist/` 可用于静态托管，资源使用相对路径；运行无需素材服务或 API 密钥。

## 操作

- A / D 或方向键：移动；Space / W / ↑：跳跃，解锁后二段跳。
- 按住 J 或鼠标左键：攻击；K：职业技能；Shift / L：无敌冲刺。
- E：房门、物品和楼层出口交互；M：地图与旅途手记；Esc：暂停。
- 升级、剧情面板：点击或数字 1–4。
- 手机支持触控，建议横屏游玩。

## 当前内容

- 灰烬骑士：三段连斩、重击碎甲、月刃风暴。余火秘法师：双发火球、持续燃烧与死亡传火。暗夜游侠：穿透箭、九箭齐射。
- 每局随机 3–5 章，每章 12–14 个连通房间。门庭开场、王座收尾，中途抽取书库、骨窟、钟楼；五种平台布局，分岔探索商店、遗灯、试炼、秘库和圣所。
- 每章两种不同精英、一名领主。五种领主拥有不同攻击组合和半血阶段；十种精英技能原型，包含预警与反击间隔。击败精英依次解锁二段跳和破障冲刺。
- 16 类遗物与赐福，包括冰火反应、穿透剑气、环绕魂火、弹丸反弹、死亡爆裂、血债和房间护盾。升级与宝箱提供三选一，金币可购买遗物和治疗。
- 遗灯可以保留记忆或烧成力量，献祭以生命换伤害，试炼自愿挑战。最终可以摧毁王冠、解救莉娅或戴冠；真结局要求至少三段记忆且腐化不超过一。
- 五章独立背景，13 个像素角色/怪物素材家族、96 张动画图；定向刀光、碎甲、命中停顿和合成音效。
- 当前楼层内保留房间状态；最高击杀、已达成结局和静音设置保存在本地。

本次重构借鉴《以撒的结合》的房间用途、代价选择和遗物联动，采用原创剧情与横版战斗。当前内容规模仍有限：每章一张背景配合布局变化，部分精英复用素材家族；尚无长期天赋树、局中存档、手柄或联网功能。移动端已做浏览器尺寸和触控验证，尚未做实体手机性能测试。

## 技术与验证

TypeScript + Vite + Three.js。960×540 像素画布通过 Three.js 着色器呈现，自定义二维平台碰撞以 60Hz 更新。角色使用 LuizMelo 的 CC0 像素动画，特效用代码绘制，背景为本地 AI 生成图像。来源及授权见 [ASSET_CREDITS.md](ASSET_CREDITS.md)。Web Audio 合成音效。

- `npm test`：随机地图、战斗、剧情与结局回归。
- `tests/browser-check.mjs`：实际按键/触控与界面流程。
- `tests/polish-check.mjs`：连招命中、碎甲、领主转阶段。
- `tests/journey-browser.mjs`：三职业动作、剧情结局与两种操作策略的短时难度信号。

浏览器脚本默认使用 5190 端口的生产预览。测试钩子只在开发模式或 `?test=1` 下暴露。设计、截图和验证记录存于本地 `artifacts/`，不随仓库上传。
